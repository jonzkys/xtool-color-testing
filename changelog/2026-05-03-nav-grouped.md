title: Top nav grouped into four roots
summary: Tests · Loom · SVG layers · Library · Palette · Spectrum · Saved are now bucketed under Testing / Materials / Engraving / Experimental.

The top bar grew with the project — seven flat tabs plus a duplicated
page title was getting noisy. The same pages now sit under four
hover-or-click root menus: **Testing**, **Materials** (Library +
Palette), **Engraving** (Loom + SVG layers), and **Experimental**
(Spectrum, Spectrum 2D, Saved). The active root carries the same
metallic-pressed underline; the active child gets a primary tick
inside the menu.

Nothing moved or was renamed — same routes, same shortcuts.
